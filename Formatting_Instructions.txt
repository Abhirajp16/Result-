TIPS:
================================================================================

1. Use "Styles" in Word for consistent formatting:
   - Create style for "Chapter Heading"
   - Create style for "Section Heading"
   - Create style for "Body Text"

2. For automatic Table of Contents:
   - Apply Heading 1 to chapter titles
   - Apply Heading 2 to section titles
   - Go to References → Table of Contents → Insert

3. For automatic List of Figures:
   - Add captions to all figures
   - Go to References → Insert Table of Figures

4. Save frequently to avoid losing work!

5. Keep a backup copy on cloud storage (Google Drive, OneDrive)
